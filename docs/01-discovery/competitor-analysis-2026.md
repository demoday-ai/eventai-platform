## 0. Главный вывод (verdict)

**Прямого аналога EventAI не существует — ни в мире, ни в РФ.** Но окно сузилось: за 2025-2026 conversational AI-ассистент стал _стандартной фичей_ крупных платформ (Cvent, Bizzabo, Swapcard, Grip), а не уникальным преимуществом. Значит наш ров — **не «у нас есть AI»**, а специфический стек под образовательный Demo Day, которого нет ни у кого:

1. **Авто-кластеризация сотен проектов по залам/трекам** по содержанию (никто из 13 проверенных не делает — треки везде задаёт организатор вручную).
2. **Матчинг «эксперт ↔ проект» по тегам и критериям оценки** (у всех matchmaking — person-to-person или person-to-exhibitor; сущности «проект-команда-эксперт-жюри» нет ни у кого).
3. **Многоролевой гость** (инвестор / HR / партнёр / ментор) с разными сценариями.
4. **Структурированный follow-up пакет** (конспект, контакты, LOI, next steps).
5. **Telegram-нативность** (у всех — собственное web/mobile-приложение, у Bizzabo ещё и железо).
6. **Цена под бесплатный образовательный формат** (enterprise-игроки — $18-250K+/год).

Рынок распадается на **несвязанные куски, и их пересечение пусто** — это и есть наша ниша.

## 2. «Четыре куска рынка, пересечение пусто»

Рынок РФ распадается на оси, каждая закрывает только одну:

| Ось | Кто | Чего не хватает до нашего кейса |
|---|---|---|
| Билеты / регистрация | Timepad, Radario, Qtickets, Ticketscloud, Яндекс Билеты | нет AI, нет работы с проектами/ролями, не Telegram |
| Афиша / каталог / бронь | Leader-ID, VK Мероприятия, Яндекс.Афиша, GetEvent | discovery, не кураторство |
| Telegram + навигация по докладам | Demo-Hero (JUG Ru), ConfAiBot (зарубеж) | tinder/правила без AI; либо только справочный Q&A и не РФ |
| AI + нетворкинг людей | NooSoft, MatchMe, Matchbox, Random Coffee | people-to-people, не курирование проектов |
| Бэк-офис хакатона | Codenrock | веб-оценка, не агент для гостя |

Пересечение всех осей (AI + многоролевость + Telegram + Demo Day с сотнями проектов) = **EventAI**.

## 3. Карточки конкурентов (история + статус 2026)

### 3.1 Глобальные conference-платформы

- **Cvent** (США, 1999). «Голубой кит» рынка: NYSE → выкуп Vista (2016) → SPAC обратно на NASDAQ (2021, EV ~$5.3B) → **выкуп Blackstone, закрыт июнь 2023, EV ~$4.6B**. Скупает рынок: Jifflenow+iCapture (2024), Splash (2024), ~$700M на сделки включая ON24 (дек'25). AI: **CventIQ** (июн'25) — рекомендации, networking-матчинг, AI-саммари, генерация контента. Цена ~$80-250K+/год. _Слепые зоны: нет Telegram, нет кластеризации проектов, нет эксперт-проект матчинга, под корпоративный MICE._
- **Swapcard** (Франция, 2013). Пивот из цифровых визиток в event-networking, ~$20M выручки. Движок **Gismo** (граф, non-generative) + генеративный **Sherlock** (AI-ассистент участника, дек'25) и **EVAA** (оркестрация). **Самый близкий по форме конкурент** (chat-first + персонализация + роли), но general-purpose под trade shows; нет кластеризации проектов, эксперт-проект матчинга, дорогой, без Telegram.
- **Bizzabo** (Израиль/США, 2011, ~$226M привлечено). Скупал AI и железо (x.ai, Klik SmartBadge $13.5M). AI-копилот **Bizzy** (мар'26). Дорого: floor ~$18K/год + add-on + бейджи. Под B2B/enterprise.
- **Whova** (США, 2012-13). Редкая bootstrapped-история до ~$15M ARR на массовых конференциях; сильное networking-приложение, относительно доступна (неск. тыс. $/событие, 3%+$0.99 за билет). Крупных ген-AI анонсов 2025-2026 не зафиксировано. Классическое «приложение конференции».
- **Brella** (Финляндия, 2016, ~$11.4M). Лидер intent-based matchmaking, ~$15M выручки. Есть типы встреч investor-startup / mentor-mentee. Генеративный AI — в roadmap. Enterprise + 2% комиссия.
- **Grip** (Великобритания, 2016, ~$14.5M). AI-матчмейкинг (16 ML-алгоритмов, ~70 млн рекомендаций/год) + LLM **AI Assistant**, авто-шедулер встреч MustMeet. Под trade show / лидген экспонентов. **Поправка: НЕ куплен RX** (RX — клиент и член совета, не владелец).

### 3.2 Хакатон / Demo Day / AI-судейство

- **Devpost** (США, 2009). Крупнейшая хакатон-платformа (4M+ разработчиков). Submission + judging + showcase, богатая ролевая модель (вкл. mentor/judge). **AI почти нет** (авто-усреднение оценок ≠ AI). Нет логистики залов, навигации гостя, Telegram, РФ. **Поправка: не куплен.**
- **Devfolio** (Индия, 2018, web3). Ставка 2026 на **Agentic Judging** — AI-агент клонирует сабмишн в песочницу и делает code-level оценку (28 AI-судей на одном ивенте). AI заточен под оценку кода под крипто-баунти, не под навигацию гостя.
- **DoraHacks** (США, 2018, ~$38.2M, web3). **BUIDL AI 4.0** — AI-со-организатор + AI-судейство по критериям. Онлайн, crypto-фокус.
- **lablab.ai** (2023, ARR ~$18.6M). **Verdict**: SCOUT (авто-обогащение проектов, извлечение GitHub/demo, **кластеризация по темам**, конкурентная разведка) + JUDGMENT (AI-судейство по рубрике). **Ближайший по AI-обработке проектов**, но онлайн, без логистики залов, навигации гостя, Telegram, эксперт-матчинга, follow-up.
- **HackerEarth** (США/Индия, 2012). B2B техоценка/найм + хакатоны Sprint. **Поправка: сделки с Certa НЕ существует** (Certa.ai — несвязанная комплаенс-компания; старый док ошибался).
- **MLH** (США, 2012). Лига студенческих хакатонов (300+/год, 65k студентов). **Купила DEV/dev.to (18.02.2026).** Комьюнити + спонсоры; логистика залов — методички, не софт.
- Прочие: **Taikai** (Португалия, web3), **Hackathon.com/BeMyApp** (каталог), **Cerebral Valley** / **Bolt «World's Largest Hackathon»** (нетворк/промо, single-venue или разовое).

### 3.3 Российские / локальные

- **Demo-Hero (@jugru_conf_bot)** — JUG Ru. **Эталонный предшественник:** доказал спрос на Telegram-навигатор по конференции, но примитивен (онбординг «пол + чем занимаешься», tinder-механика не масштабируется на сотни проектов, нет AI/кластеризации/многоролевости/follow-up). Его слабые места = наши дифференциаторы.
- **Codenrock** — РФ-платформа хакатонов/CTF: регистрация, команды, GitHub, авто-метрики, оценка экспертами по критериям, «AI Workspace». Бэк-офис хакатона, не агент для гостя; не Telegram.
- **NooSoft** (2024-25) — каждому участнику AI-агент-нетворкер. Есть AI, но **не Telegram** и только знакомства людей.
- **MatchMe** (2025-26) — Telegram-бот нетворкинга с AI-подбором людей. AI+Telegram, но узкий people-matching.
- **ConfAiBot** (зарубеж, Codely, €) — AI в Telegram/WhatsApp, RAG-Q&A по программе из Notion. Ближайший зарубежный по форме, но только справочник; иностранный вендор — мимо импортозамещения.
- **Билетники/афиши** (Timepad, Radario, Qtickets, Ticketscloud/МТС, Яндекс, VK Мероприятия, Leader-ID) — регистрация/билеты/бронь, без AI и работы с проектами.
- **Целевые клиенты, не конкуренты:** Skillbox, Leader-ID, AI Talent Hub — проводят демо-дни вручную, без технологического слоя навигации/матчинга.

## 4. Истории провалов и консолидации (урок для питча)

- **Hopin** — символ COVID-пузыря: с нуля до **~$7.75B (2021)**, после пандемии ядро (Events+Session) продано RingCentral за **$15M** (авг'23, ~99.9% уничтожения стоимости), остатки → Bending Spoons. **Урок:** универсальная платформа без ниши и устойчивого спроса не выживает; pandemic-bump ≠ durable demand.
- **Run The World** (a16z, >$15M) → куплена EventMobi, сервис закрыт сен'23. **Splash** → куплена Cvent (2024). **Boomset** → поглощена Hopin (2021). **Presdo** (ранний matchmaking) — де-факто dormant.
- **Тренд 2025-2026 — эра консолидации:** Cvent (Blackstone) скупает рынок, RingCentral подобрал Hopin, EventMobi — Run The World. Крупные собирают всё; нишевые уходят в поглощения.

**Вывод для нас:** выживают продукты с чёткой нишей и устойчивым спросом (организатор образовательного DD, повторяющееся событие), а не universal-платформы на хайпе.

## 6. Готовый блок для слайда «Конкуренты»

**Структура:** 4 разрозненных куска рынка → пустое пересечение → EventAI.

**Тезис:** «AI-ассистент на мероприятии в 2026 — уже не преимущество (есть у Cvent, Swapcard, Bizzabo). Преимущество — то, чего нет ни у кого: авто-кластеризация сотен проектов по залам, матчинг эксперт-проект, многоролевой гость, follow-up — в Telegram, под образовательный Demo Day, на рынке РФ, где западные SaaS недоступны.»

**Три якоря:**
- _Взрослый рынок дорог и не про нас:_ Cvent $80-250K/год, Bizzabo $18K+/год + железо — под корпоративный MICE, без Telegram и кластеризации проектов.
- _Предшественник доказал спрос:_ Demo-Hero (JUG Ru) — Telegram-навигатор по DD, но без AI; мы заменяем tinder семантикой и добавляем 4 недостающих слоя.
- _Урок рынка:_ Hopin ($7.75B → $15M) — universal без ниши не выживает; мы — узкая ниша с повторяющимся спросом.

## 7. Честные риски (для defensibility-раздела)

- **Окно сужается:** Swapcard Sherlock / lablab.ai Verdict ближе всех — chat-first AI + (у lablab) кластеризация по темам. Если кто-то добавит Telegram + эксперт-матчинг + multi-role гостя, дифференциация тает. Ров — скорость, доменная экспертиза, встроенность в AI Talent Hub, и операционный стек целиком, а не одна фича.
- **Отрицание «аналога нет» — по открытому поиску:** закрытые корпоративные решения могли не попасть в выдачу.
- **Финансовые цифры частных компаний** расходятся между агрегаторами; enterprise-цены публично не раскрыты.
